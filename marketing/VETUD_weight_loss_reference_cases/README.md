# VETUD — Before-and-after photo research (20 reference cases)

Prepared 23 November 2026.

**The archive organizes 20 externally published cases as research references. No third-party photographs were downloaded or uploaded.** The original pages are linked in each case folder. Some original references are galleries rather than single-person stories; those are explicitly flagged.

## Contents
- `index.html` — private research index linking to original cases
- `case_index.csv` / `case_index.json` — source + approval tracker
- `cases/Case-01` through `cases/Case-20` — individual case details and clickable `.url` shortcuts

## Permissions workflow before publication
1. Identify each photograph's photographer or publisher and license holder.
2. Obtain a written commercial-use image license, and written informed consent from identifiable subjects where appropriate.
3. Verify the before/after photographs concern the same person and document the dates and any image adjustments.
4. Verify all quantities and contextual claims; do not imply results were caused by VETUD products or retatrutide unless substantiated.
5. Verify local rules for prescription/experimental drug advertising and testimonials before releasing any image.
6. Only then add licensed image files to the matching case folder as `before.jpg` and `after.jpg`.

This file set is meant for a PRIVATE editorial / compliance workspace, not for a public `vetud.com` endpoint.
