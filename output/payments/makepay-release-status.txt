MakePay checkout repair - 2 November 2026

Root cause
The official merchant API returns https://pay.makecrypto.io/payment/<uid>.
Both our backend plugin configuration and storefront expected www.makepay.io.
The backend therefore raised "MakePay payment-link correlation failed" before
saving a payment session. The storefront's generic error concealed this cause.

Source: https://www.makecrypto.io/documentation/makepay/getting-started/overview

Completed
- Backend checkoutBaseUrl and storefront redirect allowlist now use the current
  official checkout origin, with matching optional environment overrides.
- Four regression tests pass, including mismatched amount, currency, company,
  session, installation, provider and external-origin rejection.
- Backend lint, TypeScript and production build pass.
- Storefront lint, TypeScript and Vercel production build pass.
- The actual failed merchant link passes the corrected backend verification.
  Its hosted page returns HTTP 200. No payment or order was submitted.
- The staged checkout's compiled browser code contains pay.makecrypto.io and
  no longer contains www.makepay.io for MakePay navigation.
